# Release v0.1.28 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the current `main` contents as the verified `v0.1.28` release.

**Architecture:** The release changes only workspace and lockfile version metadata. The existing tag-triggered GitHub Actions workflow performs verification, cross-platform builds, GitHub Release creation, artifact upload, and optional crates.io publication.

**Tech Stack:** Rust workspace, Cargo, Git, GitHub Actions, GitHub CLI



Expected: no whitespace errors and only seven version replacements.
